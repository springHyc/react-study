# useReducer 订阅更新 Demo

这个 demo 展示了如何使用 useReducer 实现订阅模式，让多个组件可以订阅同一个状态的变化。

## 核心概念

### useReducer
- **作用**: 用于管理复杂的状态逻辑，比 useState 更适合处理多个子值的状态
- **语法**: `useReducer(reducer, initialState)`
- **返回**: `[state, dispatch]`

### 订阅模式
- **作用**: 通过订阅机制，多个组件可以监听同一个状态的变化
- **优势**: 解耦状态管理和组件，让状态变化可以被多个地方监听和响应

## 使用场景

- 多个组件需要共享和响应同一个状态
- 需要解耦状态管理和组件
- 需要实现观察者模式

## 实现要点

1. 创建一个带订阅功能的 reducer 类
2. 在 reducer 中实现订阅和通知机制
3. 组件通过 subscribe 方法订阅状态变化
4. 状态改变时自动通知所有订阅者
